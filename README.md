# Gerenciador de Lista de Jogos em Python

Este é meu primeiro projeto desenvolvido em Python durante meus estudos de programação.

O objetivo é praticar conceitos fundamentais da linguagem por meio de programas que permitem gerenciar uma lista de jogos.

## Arquivos do projeto

- **`main.py`** — versão principal do Gerenciador de Jogos, com menu interativo e gerenciamento completo da lista.
- **`menu_jogos.py`** — exercício separado de menu interativo, desenvolvido durante o aprendizado.

## Funcionalidades do `main.py`

- Listar jogos cadastrados com suas posições.
- Pesquisar jogos.
- Adicionar novos jogos.
- Impedir o cadastro de jogos duplicados.
- Remover jogos cadastrados.
- Consultar jogos por posição.
- Validar posições informadas.
- Exibir a quantidade total de jogos.
- Apresentar os resultados finais.

## Funcionalidades do `menu_jogos.py`

- Mostrar jogos cadastrados.
- Adicionar novos jogos.
- Impedir jogos duplicados.
- Remover jogos cadastrados.
- Encerrar o programa pelo menu.

## Tecnologias utilizadas

- Python 3

## Conceitos praticados

- Variáveis e listas.
- Condicionais (`if`, `elif` e `else`).
- Laços de repetição (`for` e `while`).
- Operadores (`in`, `not in` e `and`).
- Métodos de listas (`append` e `remove`).
- Entrada de dados com `input()`.
- Conversão de dados com `int()`.
- Validação de índices com `len()`.
- Menus interativos.

## Como executar

1. Tenha o Python 3 instalado.
2. Clone ou baixe este repositório.
3. Abra a pasta do projeto no VS Code.
4. Execute `main.py` ou `menu_jogos.py`, conforme o programa desejado.
