# Gerenciador de Lista de Jogos em Python

Este é meu primeiro projeto desenvolvido em Python durante meus estudos de programação.

O objetivo é praticar conceitos fundamentais da linguagem por meio de um programa que permite gerenciar uma lista de jogos.

## Funcionalidades

- Listar jogos cadastrados.
- Pesquisar jogos.
- Adicionar novos jogos.
- Impedir o cadastro de jogos duplicados.
- Remover jogos cadastrados.
- Consultar jogos por posição.
- Exibir a quantidade total de jogos.

## Tecnologias utilizadas

- Python 3

## Conceitos praticados

- Variáveis e listas.
- Condicionais (`if` e `else`).
- Laços de repetição (`for`).
- Operadores (`in` e `not in`).
- Métodos de listas (`append` e `remove`).
- Entrada de dados com `input()`.
- Validação de índices com `len()`.

## Como executar

1. Tenha o Python 3 instalado.
2. Abra a pasta do projeto no VS Code.
3. Execute o arquivo `main.py`.
